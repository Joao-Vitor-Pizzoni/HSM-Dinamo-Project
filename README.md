# HSM Dinamo Project

This repository contains C implementations for cryptographic operations using the HSM Dinamo API.
The project is divided into three main components:

## 1. Hash Module

The first code implements iterative hash operations in C using the HSM Dinamo API.
It demonstrates how to securely compute hashes with hardware support.

## 2. Signature Module

The second code focuses on digital signatures.
It shows how to generate and verify signatures using the HSM Dinamo, providing secure message authentication.

## 3. ECDH Module

The third code implements Elliptic Curve Diffie-Hellman (ECDH) key exchange.
It demonstrates how to securely establish shared keys between two parties using the HSM Dinamo API.

## Technologies

* C Programming Language
* HSM Dinamo API
* Cryptographic operations: Hash, Digital Signature, ECDH

## Notes

Each module is implemented independently and can be compiled and executed separately.
The code is structured to allow easy experimentation and extension of cryptographic functionalities.
